# Geophysical Inversion Summary

Geophysical inversion estimates subsurface or source parameters from observed data. In earthquake science, inversion can be used to infer fault slip, rupture evolution, velocity structure, or source mechanisms. The problem is often ill posed: multiple models can explain the same observations. Regularization, prior information, and uncertainty analysis are therefore important.

Machine learning can support inversion by accelerating surrogate models, identifying waveform patterns, or combining heterogeneous observations. However, physical constraints and uncertainty reporting remain important because a fluent model output is not the same as a validated geophysical conclusion.
